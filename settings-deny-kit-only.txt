# 킷 템플릿(global/settings.json.template)의 permissions.deny 에는 있고 이 사용자가 라이브 ~/.claude/settings.json 에서 의도적으로 뺀 규칙 — 한 줄 하나.
#   라이브에 있어서는 안 된다는 목록이 아니다(라이브에 있으면 킷 기본값 그대로인 것).
# 형식: deny 규칙 원문 그대로(앞뒤 공백 포함 완전일치) · '#' 으로 시작하는 줄과 빈 줄은 무시.
# 소비처: doctor.sh [5g] 전역 deny 대조 — 템플릿에만 있는 규칙 중 여기 없는 것 = 경고, 여기 있는데 템플릿에 없는 것 = 등록이 낡음 경고,
#   여기 있는데 라이브·템플릿에 다 있는 것 = ✓ 정보 줄(경고 아님).
# 현재 차이 조회: comm -13 <(jq -r '.permissions.deny[]' ~/.claude/settings.json | sort -u) <(jq -r '.permissions.deny[]' global/settings.json.template | sort -u)
# 아래 규칙들: 라이브에선 deny 대신 다른 층이 맡는다 — rm·find·reset = destructive-cmd-ask 확인창, 강제 push = git-push-guard,
#   kill = 과속방지턱이라 라이브엔 두지 않는다(2026-11-19 사용자 승인).
Bash(rm -rf *)
Bash(rm -fr *)
Bash(rm -Rf *)
Bash(rm -fR *)
Bash(rm -r -f *)
Bash(rm -f -r *)
Bash(rm -R -f *)
Bash(rm -f -R *)
Bash(rm --recursive *)
Bash(find * -delete*)
Bash(git reset --hard*)
Bash(git push --force*)
Bash(git push -f*)
Bash(kill -9 *)
Bash(killall *)
