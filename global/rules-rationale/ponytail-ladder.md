**경위:** 2026-09-03 규약 다이어트 전 프로젝트 CLAUDE.md 는 "코드 덜 짜기·최단 diff·오버엔지니어링 지양을 적용하되 다음은 절대 생략 대상이 아니다(5항목)" 였다. 다이어트가 앞 절(래더 본문)을 떨어뜨리고 예외 조항(하한선 5항목)만 남겼다. 2026-09-07 웹 원문 대조로 발견해 전역에 복원(스택 불문 방법론 = 전역 단일정본, 배치 3규칙 ①).

**원문(DietrichGebert/ponytail `skills/ponytail/SKILL.md`, v4.9.0 당시 — 아래 v5.3.3 절이 우선):** 래더 7단 = 존재 필요(YAGNI) → 코드베이스 재사용 → stdlib → 플랫폼 네이티브 → 설치된 의존성 → 한 줄 → 최소 코드, 첫 성립 단에서 정지. "래더는 문제를 이해한 뒤에 탄다 — 읽기는 절대 게으르지 않는다". 규칙 = 단일구현 추상화·미래용 스캐폴딩 금지, 삭제 > 추가, 최소 파일·최단 diff, 버그픽스 = 호출처 전부 grep 후 공유 지점 루트코즈 1회. 절대 안 자르는 5항목 = 트러스트 경계 입력검증·데이터 손실 방지 에러처리·보안·접근성·명시 요청. 비자명 로직엔 실행 가능한 검증 1개("검증 없는 게으른 코드는 미완성"). 마커 `ponytail: <천장>, <업그레이드 경로>`. 부속 스킬 `/ponytail-review`(dead·stdlib·native·yagni·shrink 5태그, 정확성·보안 제외) · `/ponytail-debt`(마커 장부, 트리거 없으면 `no-trigger`).

**독립 실측(JetBrains AI 블로그 2026-07, Sonnet 5, 80쌍):** LOC −15.4% 중앙값(큰 빌드 −31%, 이미 린한 코드 ≈0), 비용 −10.3%(p=0.004), 품질 65 동일/9 악화/6 개선. 저자 벤치(Haiku n=4)의 −54%/−20% 는 과잉설계 함정이 있는 과제에서만. **스킬 폴더에만 두면 10세션 무발동** — 훅 주입 또는 상시 로드 규약에 박아야 효과. 우리는 CLAUDE.md 상시 로드라 동등 — 단 서브에이전트 범위(자식이 전역 CLAUDE.md 를 받는가)는 2026-11-17 실측 = Agent 도구 서브에이전트는 전역 CLAUDE.md 를 받는다(도구 없이 절 제목·훅 파일명을 원문 인용) → SubagentStart 주입 불요. Workflow agent·`api-ro` 검증자(`--system-file` 로 레포 CLAUDE.md 만 받음)는 미실측.

**로컬 판정(v4.9.0 당시 — 아래 v5.3.3 절이 우선):** 채택 = 래더·규칙·마커·하한선·검증 의무(로컬이 더 강함: 경합 E2E·반증검사·단위테스트 기본). 미채택 = 출력 규칙(코드 먼저·3줄 요약 — 로컬 "변경 후 요약"과 충돌)·강도 3단·상시 `/ponytail-review` 관점(워크플로 관점 5개 = 토큰 증가, 필요 시 빌트인 `/simplify`). 장부는 스킬 승격 없이 프로젝트 `.claude/scripts/ponytail-debt.sh` 한 개(파일 경로가 프로젝트값이라 프로젝트 배치).

**주의(실사고, 예시 레포 memory [[comment-asserts-facts-outside-the-code]] 계열):** `ponytail:` 주석이 "상한에 닿으면 알린다"처럼 동작을 약속했으면 그 동작이 실재하는지 확인한다(E4·BO 수강현황 2회 재발). 기능을 붙일 때 그 자리의 옛 `ponytail` 을 먼저 읽어라 — 옛 제약 우회용 관대한 규칙은 제약이 풀리는 순간 정반대 결함이 된다.
